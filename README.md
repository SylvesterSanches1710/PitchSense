# PitchSense

An AI-powered football analytics platform: data-driven match outcome prediction and +EV betting opportunity identification, built as a learning project and portfolio piece.

## Status
🚧 Phase 1 — Data Collection (in progress)

## Stack
Python · PostgreSQL · SQLAlchemy · FastAPI · Next.js · scikit-learn / XGBoost / LightGBM / CatBoost · SHAP

## Local development

1. Copy `.env.example` to `.env` and fill in values
2. Start the database: `docker compose up -d`
3. Create a virtual environment and install dependencies (see below)

## Disclaimer
This project is a data-driven decision-support tool for personal learning and analysis. It does not guarantee profitable betting outcomes, and no prediction model consistently beats bookmaker pricing.
